# ChatAlias

Клиент-сайд Fabric-мод для Minecraft **1.21.4**. Заменяет сокращения в исходящих сообщениях на полные фразы — удобно для модераторов.

## Что делает

Вы набираете в чат:
```
Вы замучены за !r
```
А на сервер уходит:
```
Вы замучены за спам
```

Работает и в обычном чате, и в командах (можно отключить отдельно):
```
/mute Player1 30m !spam   →   /mute Player1 30m спам
```

## Установка

Положите в `.minecraft/mods/`:

1. **Fabric Loader** 0.16+
2. **Fabric API** — https://modrinth.com/mod/fabric-api
3. **YetAnotherConfigLib (YACL)** 3.6.6+1.21.4 — https://modrinth.com/mod/yacl
4. **Mod Menu** (опционально, нужен для GUI настроек) — https://modrinth.com/mod/modmenu
5. **ChatAlias** (этот мод) — `chatalias-1.0.0.jar` из `build/libs/`

## Использование

Открывайте экран в игре: **ESC → Mods → ChatAlias → Configure**.

В меню можно:
- Включать/выключать замену целиком
- Включать/выключать замену внутри команд (со слэшем)
- Добавлять/удалять/редактировать алиасы в формате `ключ = значение`

Конфиг лежит в `.minecraft/config/chatalias.json` — можно править вручную:

```json
{
  "enabled": true,
  "applyToCommands": true,
  "aliases": {
    "!r": "спам",
    "!f": "флуд",
    "!warn": "предупреждение"
  }
}
```

## Сборка из исходников

Требуется JDK 21+.

```bash
./gradlew build
```

Готовый `.jar` будет в `build/libs/chatalias-1.0.0.jar`.

## Примечания

- Длинные ключи имеют приоритет над короткими: `!warn` и `!w` могут сосуществовать.
- Замена строго подстрочная, без regex — спецсимволы экранировать не нужно.
- Алиасы не должны конфликтовать с командами сервера. Если вы используете префикс `!` для команд — выбирайте другой префикс для алиасов, например `;r`, `;f`.
